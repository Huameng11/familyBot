# 🤖 FamilyBot — 24 小时全能家庭管家大中台

FamilyBot 是一款专为树莓派（Raspberry Pi）或家庭本地服务器打造的 **24 小时全能家庭管家大中台**。系统采用轻量级内网 RAG（检索增强生成）架构，整合了 AI 动态问答、全库定时巡检推送、药品说明书 OCR 识别、以及物资、备忘、日历与菜谱的一站式移动端管理。

------

## 🌟 系统愿景与设计原则

- **隐私优先与本地掌控 (Local-First)**：所有数据（药品、物资、备忘、日程、对话记录）均保存在本地 SQLite 数据库中。前端采用 PWA 架构，配合 Service Worker 离线缓存，确保局域网秒开与断网可用。
- **去闲聊化与精准 RAG**：内置多意图路由网关（`Intent Router`），提问时自动识别涉及模块，仅调取相关数据表拼装 System Prompt，降低 Token 消耗并提升回答精准度。
- **绝对时间锚点**：在 Prompt 中动态注入当前系统时间与对比日期，彻底解决大语言模型对于 “今天、明天、还剩几天过期” 等相对时间的计算混淆问题。
- **防撑爆移动端布局**：针对手机屏与平板视窗优化，全界面采用竖排防撑爆卡片与全宽折叠面板，适配移动端轻量交互。

## 📋 系统核心功能详解

### 1. 🤖 AI 智能问答中台 (RAG & 意图网关)

- **多意图路由分析**：提问发送后，系统优先通过轻量网关（`analyze_intent`）解析语义，自动识别提问是否关联 `medicine`（药箱）、`storage`（仓库）、`calendar`（日历）、`recipe`（菜谱）或 `memo`（备忘录）。
- **智能上下文继承**：当用户进行短句追问（如 “放在哪个抽屉？”、“还有几天？”）时，系统能结合最近 10 条历史对话，自动继承上一轮回答的主题意图并调取对应数据库。
- **全局兜底防御**：若提问属于复合场景或模糊查询，系统会自动挂载除菜谱外的全库基础数据，保证回答不漏掉关键信息。
- **绝对时间精准推演**：自动计算药品剩余保质期（天数 / 月数）、日程倒计时，准确判断 “已过期” 或 “即将过期”。

### 2. 💊 智能药箱管理 (Medicine)

- **全属性记录**：支持记录药品名称、剩余数量、存放位置、过期时间、用法用量（如 “一日三次，饭后服”）及功效说明。
- **过期与耗尽预警**：系统自动识别保质期，并在早报与 AI 问答中针对已过期或临期（30 天内）药品进行警示；同时精准识别 `0`、`用完`、`缺货` 等耗尽状态。
- **Agnes Vision 视觉 OCR**：集成大模型视觉能力，上传药品包装或说明书照片，即可自动提取【用法用量】与【功效说明】并填入表单。

### 3. 📦 家庭物资仓库 (Storage)

- **全屋物资定位**：记录物品名称、分类（如 “日用品”、“工具”、“食品”）、储量、具体存放位置及备注。
- **低库存预警**：支持对数量标注为 “缺”、“少”、“需补” 或具体数字偏低的物资进行自动筛查，防止日常用品断货。

### 4. 📅 家庭日历与行程安排 (Calendar)

- **日程与纪念日追踪**：记录事件标题、日期、分类（如 “生日”、“缴费”、“出行”）、地点、提醒时间及详细备注。
- **时间线展示**：按事件日期升序排列，自动与每日巡检结合，提早提醒今日与近期日程。

### 5. 📝 家庭备忘录 (Memo)

- **杂事与高频信息归档**：适合存储水电气户号、门禁密码、家具尺寸、保险单号、待办事项等琐碎数据。
- **倒序快速检索**：最新添加的备忘录优先展示，AI 问答可随时调取备忘中的关键数值。

### 6. 🍳 家庭菜谱与烹饪指南 (Recipe)

- **家常菜谱管理**：记录菜名、分类、制作难度、所需食材、详细烹饪步骤及参考教程链接。
- **按需加载机制**：菜谱模块数据仅在明确询问 “做饭 / 吃什么 / 菜谱” 时挂载，避免占用常规问答的 Prompt 空间。

### 7. ⏰ 全天候巡检与多通道早报引擎 (Notifier)

- 全库自动巡检：定时任务自动扫描数据库，提取：
  - 📅 **今日日程 / 纪念日**
  - 💊 **过期 / 临期药品及存量为 0 的缺药提醒**
  - 📦 **缺货 / 偏低物资补给提示**
  - 📝 **最新重点备忘录**
- **LLM 润色**：将巡检到的原始数据交由大模型生成排版优雅、带有温馨问候与 Markdown 高亮格式的 “每日汇报”。
- 多通道同步下发：
  1. **企业微信 Webhook**：自动发送 Markdown 格式卡片至家庭 / 工作群机器人。
  2. **网页端对话框**：自动插入网页端聊天历史，登录系统即可看到管家留言。
  3. **TTS 纯文本清洗**：自动去除 Markdown 语法、Emoji 表情及标点符号，提取纯文本保存至 `data/msg.txt`，供小爱音箱或 Home Assistant 进行语音播报。

### 8. ⚡ 实用前端特性

- **AI JSON 批量导入**：所有数据模块（药箱、仓库、日历、菜谱、备忘录）均支持使用 AI 生成的 JSON 数据一次性批量导入，无需手动逐条添加。
- **语音输入与合成朗读**：聊天框集成了浏览器原生 Web Speech 语音识别（语音转文字）与语音合成（朗读管家回复）。
- **剪贴板兼容性降级**：内置一键复制回答功能，兼容 HTTP 与 HTTPS 环境下的剪贴板写入。

## 📖 详细功能使用与操作指南

### 1. 与 AI 管家对话 (智能问答)

在首页 **【管家问答】** 输入框中，您可以直接使用自然语言提问：

- **查询药品**：“感冒药放在哪里了？” / “家里还有布洛芬吗？有没有过期？”

- **查找物资**：“螺丝刀在哪个箱子？” / “家里还有几卷垃圾袋？”

- **行程与提醒**：“今天有什么安排？” / “离老婆生日还有多少天？”

- **查阅备忘**：“电费户号是多少？” / “客厅窗帘的尺寸记录了吗？”

- **询问菜谱**：“今晚想吃红烧肉，怎么做？”

- 连续追问示例

  > 用户：“布洛芬放在哪？”
  >
  > FamilyBot：“布洛芬位于【医药箱 A 层】。”
  >
  > 用户：“还有几盒？”
  >
  > *(系统将自动继承 “药品” 意图，查询存量并回复)*

### 2. 使用视觉 OCR 录入药品说明书

1. 进入 **【智能药箱】** 选项卡，点击右上角 **“+ 新增药品”**。
2. 点击表单顶部的 **“📷 拍摄说明书 / 药品盒识别”** 按钮。
3. 选择或拍摄药品包装上的【用法用量】或【功效】图片。
4. 系统将自动调用 Agnes Vision 视觉模型解析图片，并将解析出的文字自动填入 `用法用量` 和 `功效说明` 输入框中，稍作确认即可保存。

### 3. 使用 AI JSON 批量导入数据

如果您有大量的初始数据（如几十种药品或物资），无需逐个手动填写：

1. 进入任意数据管理模块（如【智能药箱】或【家庭仓库】）。
2. 点击 **“⚡ 批量导入”** 按钮，打开批量导入弹窗。
3. 将您现有的数据提供给任意 AI（如 ChatGPT / Claude / 智谱），让其按弹窗内提示的 JSON 格式输出数据。
4. **格式示例（以药品为例）**：

```json
[
  {
    "name": "阿莫西林胶囊",
    "count": "2盒",
    "location": "客厅电视柜抽屉",
    "expire_date": "2026-12-01",
    "usage": "一日三次，一次一粒",
    "eff": "消炎抗菌"
  },
  {
    "name": "维生素C片",
    "count": "1瓶",
    "location": "主卧床头柜",
    "expire_date": "2025-08-15",
    "usage": "一日一次，一次一片",
    "eff": "补充维生素"
  }
]
```

将生成好的 JSON 粘贴进文本框，点击 “解析并批量导入”，系统会进行校验并一次性写入数据库。

### 4. 调试暗号与早报推送测试

若您修改了早报生成逻辑或设置了企业微信 Webhook，想要立刻查看推送效果：

1. 打开 【管家问答】 对话页面。
2. 在聊天框中输入暗号并发送：

```
open666
```

系统将绕过定时器的时钟等待，立即执行全库巡检，生成早报并同时触发：

- 企业微信机器人消息推送
- 网页端聊天记录挂载
- `data/msg.txt` 纯文本清洗与写入

### 5. 联动小爱音箱 / Home Assistant 语音播报

系统每次生成早报时，都会将文本清洗为适合朗读的纯文本存入文件 `data/msg.txt`：

- 文件位置：项目根目录`/data/msg.txt`
- 清洗效果：剔除 `#`、`*`、Emoji、Markdown 标签 及开头的问候语，将换行转换为句号。

**自动化联动流程：**

在 Home Assistant 或树莓派自动化脚本中添加触发器（如每日 07:35 或小爱音箱监听 “今天家里有什么事”）。

脚本执行 Shell 命令读取 `data/msg.txt` 内容。

将读取出的文本作为参数传给小爱音箱（或其它 TTS 引擎）进行语音播报。

## 🐳 Docker 快速部署指南

### 前置依赖

服务器 / 树莓派预先安装好 `docker` + `docker-compose`（或 docker compose v2）。

### 1. 准备部署文件

新建项目文件夹，放入以下文件：

- `docker-compose.yml`（下方完整配置）
- `.env` 配置文件（自行填写大模型密钥、Webhook、定时推送参数等）

**docker-compose.yml 完整内容：**

```yaml
services:
  familybot:
    image: 254521335/familybot:latest
    build: .
    container_name: familybot_server
    environment:
      - TZ=Asia/Shanghai
      
    ports:
      - "8000:8000"
    volumes:
      - ./.env:/app/.env
      - ./data:/app/data
      - /etc/localtime:/etc/localtime:ro
      - /etc/timezone:/etc/timezone:ro
      
    restart: always
```

### 2. 启动服务

```bash
# 后台启动
docker compose up -d

# 查看实时日志
docker compose logs -f familybot
```

### 3. 访问地址

启动成功后，局域网访问：

```
http://服务器IP:8000
```

### 常用运维命令

```bash
# 停止服务
docker compose down

# 重启服务
docker compose restart familybot

# 更新镜像并重启
docker compose pull && docker compose up -d
```

### 部署注意事项

1. 持久化说明

   ```
   ./data
   ```

    目录会挂载到容器内，数据库文件、

   ```
   msg.txt
   ```

    全部保存在宿主机，删除容器不会丢失数据。

2. 时区挂载

   容器强制同步宿主机时区，保证药品过期计算、定时早报时间准确。

3. `.env` 文件权限

   Linux 环境建议设置权限，避免密钥泄露：

```bash
chmod 600 .env
```

1. 树莓派注意

   镜像已兼容 ARM64 树莓派平台；如果首次启动镜像拉取失败，请检查 Docker 架构配置。
